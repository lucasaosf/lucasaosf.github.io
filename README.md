## 🧬 Pilares de Atuação em Destaque

1. **Taxonomia & Sistemática Filogenética (Foco Central)**: Diagnose morfológica e bioacústica de herpetofauna e ornitofauna, chaves dicotômicas, clados crípticos (complexo *Bothrops atrox*, serpentes e anuros) e redescobertas taxonômicas (*Bothrops bilineatus* após 30 anos no ES).
2. **Ecologia Computacional & Programação em R**: Pipelines avançados de mineração de ocorrências no GBIF, análise estatística multivariada de comunidades de fauna, bioestatística e modelagem ecológica (apresentado na COP30 da ONU).
3. **Automação de Relatórios & Matrizes**: Scripts em Python e R para higienização e integração de dados de campo para diagnósticos de EIA/RIMA, RAP e laudos CETESB.
4. **Engenharia de Softwares de Campo (PWAs)**: Criador da [Caderneta de Campo](https://lucasaosf.github.io/caderneta-de-campo/) e [Cubagem Florestal Smalian](https://lucasaosf.github.io/cubagem-florestal/).

## 🚀 Como Publicar no GitHub Pages

Você tem 2 opções simples para colocar seu portfólio no ar:

### Opção 1: Como seu site principal (`https://lucasaosf.github.io/`) — **Recomendado**
1. Crie um novo repositório no seu GitHub chamado exatamente: `lucasaosf.github.io`
2. No terminal (PowerShell), entre na pasta deste portfólio:
   ```bash
   cd "C:\Users\Lucas Aosf\Desktop\portfolio-lucasaosf"
   git init
   git add .
   git commit -m "feat: portfolio biokuri taxonomia e automacao"
   git branch -M main
   git remote add origin https://github.com/lucasaosf/lucasaosf.github.io.git
   git push -u origin main
   ```
3. Pronto! O GitHub Pages ativa automaticamente em `https://lucasaosf.github.io/`.

### Opção 2: Como repositório `portfolio` (`https://lucasaosf.github.io/portfolio/`)
1. Crie um novo repositório no GitHub chamado `portfolio`.
2. No PowerShell:
   ```bash
   cd "C:\Users\Lucas Aosf\Desktop\portfolio-lucasaosf"
   git init
   git add .
   git commit -m "feat: portfolio biokuri"
   git branch -M main
   git remote add origin https://github.com/lucasaosf/portfolio.git
   git push -u origin main
   ```
3. No GitHub, vá em **Settings > Pages > Build and deployment > Branch: `main` / `root`** e clique em Save.
